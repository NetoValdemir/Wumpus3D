Como os alunos entram
  1. Acrescente os alunos: cada um ganha um PIN de 4 dígitos.
  2. Escolha o plano da turma (aba Planejar → aqui, "Usar o plano em edição").
  3. Gere o código da turma e entregue, junto com os cartões de PIN.
  4. O aluno abre a tela inicial, "Sou aluno", cola o código uma vez e entra com apelido e PIN.

Os PINs organizam o acesso, mas não são proteção forte: o site é público e a conferência acontece no aparelho do aluno.

      Minhas cavernas

        Guardar no GitHub (opcional)

        Guarde turmas, planos, registros e relatórios num repositório privado seu, para usar em outro computador e ter o histórico. O token fica só neste navegador; nunca vai para o site.

        Como preparar (uma vez)

        1. Em github.com, crie um repositório novo marcado como Private (por exemplo, caverna-turmas).
        2. Vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
        3. Em Repository access, escolha Only select repositories e marque só esse repositório.
        4. Em Permissions → Contents, escolha Read and write. Dê uma data de validade (por exemplo, o fim do semestre).
        5. Copie o token e cole ao lado. Se ele vazar, apague-o no mesmo lugar e crie outro.

        O que é guardado: turmas/ (com os PINs, por isso o repositório precisa ser privado), planos/, registros/ e relatorios/. Cada envio vira uma versão no histórico do repositório. O jogo se recusa a gravar num repositório público.
